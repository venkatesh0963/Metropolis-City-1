# Metropolis City 1

Metropolis City 1 is an isometric urban simulation and sandbox game built using HTML5 Canvas and vanilla JavaScript. The application runs client-side with zero external dependencies.

## Key Capabilities

- **Terrain Sculpting**:
  - Mountain building with heights from H1 (hill) to H5 (alpine peak).
  - Digging tools for canals, lakes, and rivers.
  - Land flattening and automatic sand shoreline formation.
  - Continuous drag interpolation across tiles.
- **Zoning and Buildings**:
  - Residential, commercial, industrial, civic, and landmark structures.
  - Automatic road-facing door and path orientation.
  - Multi-level networks (surface, elevated flyovers, and underground tunnels).
- **Public Transit**:
  - Bus routes, taxi networks, passenger trains, and multi-station metro lines.
  - Sea ferry piers and international airport connections.
- **City Administration**:
  - City Hall dashboard covering budget, taxes, municipal debt, demographics, services, and trade.
  - Detailed citizen panel tracking employment, education, happiness, and individual stories.
- **Interaction & Simulation**:
  - Extinguish fires by tapping burning structures or dispatching fire departments.
  - Multi-slot save/load and undo/redo history.
  - Day/night lighting cycle and environmental overlays.

## Running Locally

Open `index.html` or `Metropolis City 1.html` directly in any standard web browser. No compilation, package manager, or web server is required.

## Controls

- **Pan**: Left-click and drag with the Hand tool, or right-click and drag.
- **Zoom**: Mouse wheel or touch pinch.
- **Build / Dig**: Select a tool and click or drag over map tiles.
- **Extinguish Fire**: Click directly on burning buildings.
- **Inspect**: Click on any resident with the Hand tool to view status.
